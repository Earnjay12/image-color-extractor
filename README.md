# Color Chip

사진 한 장에서 팔레트를 만드는 웹앱입니다.
이미지를 올리면 대표 색을 뽑고, 원하는 **느낌**으로 고른 뒤 **톤·화풍 프리셋**으로 보정해
**HEX · RGB · CMYK** 컬러칩으로 저장합니다.

```
① 이미지  →  ② 추출 느낌 선택  →  ③ 색 보정  →  ④ 결과 확인 · PNG 저장
```

## 실행 방법

빌드 도구나 서버가 필요 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.

로컬 서버로 띄우고 싶다면:

```bash
python -m http.server 5510
```

그 다음 `http://localhost:5510` 으로 접속하세요.

## 기능

### ① 이미지
- 드래그 앤 드롭, 파일 선택, 클립보드 붙여넣기(`Ctrl`+`V`) 지원
- 이미지는 브라우저 안에서만 처리되며 어디에도 업로드되지 않습니다

### ② 추출 느낌
어떤 기준으로 대표색을 고를지 정합니다. 컬러칩 개수는 기본 5개, 2~12개까지 조절.

| 느낌 | 우선하는 색 |
|---|---|
| 균형 | 이미지에서 가장 넓게 보이는 색 순서 |
| 강렬한 | 채도가 높고 눈에 확 띄는 색 |
| 부드러운 | 채도가 낮고 밝은, 편안한 색 |
| 깊은 | 어둡고 농도가 짙은 색 |
| 밝은 | 밝고 가벼운 색 |

### ③ 색 보정
뽑힌 칩에 적용됩니다. 보정 후에는 칩 왼쪽 위 작은 원으로 **보정 전 원본 색**을 함께 보여줍니다.

- **톤** — 원본 · 파스텔 · 뮤트 · 비비드 · 필름 · 모노
- **화풍** — 모네 · 반 고흐 · 마티스 · 모란디 · 클림트 · 호퍼 · 로스코 · 호쿠사이
- **미세조정** — 밝기 · 채도 · 온도 슬라이더 (프리셋 위에 겹쳐 적용)

화풍 프리셋은 그 화가의 색 경향(예: 모네=빛을 머금은 옅고 서늘한 색, 클림트=금빛)에서
영감을 얻은 해석이지, 작품의 색을 복원하는 것은 아닙니다.

### ④ 결과
- 칩마다 HEX / RGB / CMYK 와 이미지에서 차지하는 면적 비율(%) 표시
- 코드를 클릭하면 클립보드에 복사
- **PNG 저장** — 원본 이미지 + 전체 컬러칩(추출 느낌·보정 이름 포함)을 한 장에 담아 저장

## 동작 원리

### 색 추출
1. 이미지를 최대 256px로 축소하고 픽셀을 읽습니다. 투명한 픽셀은 제외합니다.
2. 각 픽셀을 sRGB에서 **CIELAB**으로 변환합니다. RGB 거리는 사람이 느끼는 색 차이와
   잘 맞지 않아서, 눈에 비슷해 보이는 색끼리 묶이게 하기 위함입니다.
3. **k-means**(k-means++ 초기화, 시드 고정)로 24개의 후보 군집을 만듭니다.
   이미지당 한 번만 실행하므로 이후 느낌·개수 변경은 재분석 없이 즉시 반영됩니다.
4. 각 군집의 중심에 **가장 가까운 실제 픽셀 색**을 대표색으로 삼습니다.
   중심값을 그대로 쓰면 원본에 없는 탁한 색이 나오기 때문입니다.
5. 선택한 느낌의 점수식(면적·밝기·채도 조합)으로 후보를 정렬하고, 이미 고른 색과
   너무 비슷한 색(ΔE 기준)은 건너뛰며 요청한 개수만큼 고릅니다.

### 색 보정
Lab 공간에서 밝기(L) 이동, 채도 배율, a/b 축 이동, 명암 대비를 조합합니다.
결과가 sRGB 색역을 벗어나면 밝기와 색상은 유지한 채 채도만 줄여 표현 가능한 가장 가까운 색으로
맞춥니다 — 단순 클리핑은 색상이 틀어지기 때문입니다.

## CMYK 값에 대하여

CMYK는 ICC 프로파일 없이 계산한 **근사값**입니다. 실제 인쇄에서 쓰이는 CMYK는 잉크·용지·
출력 장비에 따라 달라지므로 참고용으로만 쓰시고, 정확한 인쇄 색 지정이 필요하다면
Pantone 등 별도 색상 체계나 출력소의 프로파일을 사용하세요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 (4단계 플로우) |
| `styles.css` | 스타일 (라이트/다크 모드 자동 전환) |
| `js/color.js` | sRGB ↔ Lab 변환, CMYK 근사, 색역 보정 |
| `js/extract.js` | 픽셀 샘플링, k-means, 느낌별 선택 |
| `js/grade.js` | 톤·화풍 프리셋과 미세조정 |
| `js/sheet.js` | PNG 시트 내보내기 |
| `js/app.js` | 화면 연결 |

의존성 없는 순수 HTML/CSS/JavaScript입니다. 글꼴(Pretendard)만 CDN에서 불러오며,
오프라인이면 시스템 글꼴로 대체됩니다.
