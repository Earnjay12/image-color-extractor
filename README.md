# Color Chip

이미지를 올리면 그 안에서 가장 대표적인 색들을 뽑아 컬러칩으로 만들어 주는 웹앱입니다.
각 칩마다 **HEX · RGB · CMYK** 값을 함께 보여주고, 원본 이미지와 팔레트를 한 장의 PNG로 내려받을 수 있습니다.

## 실행 방법

빌드 도구나 서버가 필요 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.

로컬 서버로 띄우고 싶다면:

```bash
python -m http.server 5510
```

그 다음 브라우저에서 `http://localhost:5510` 으로 접속하세요.

## 기능

- **이미지 입력** — 드래그 앤 드롭, 파일 선택, 클립보드 붙여넣기(`Ctrl`+`V`) 모두 지원
- **컬러칩 추출** — 기본 5개, 슬라이더로 2~12개까지 조절
- **색상 코드** — HEX / RGB / CMYK. 코드를 클릭하면 클립보드에 복사됩니다
- **면적 비율** — 각 색이 이미지에서 차지하는 비중을 % 로 표시
- **PNG 다운로드** — 원본 이미지 + 전체 컬러칩을 한 장에 담아 저장

이미지는 브라우저 안에서만 처리되며 어디로도 전송되지 않습니다.

## 색상을 뽑는 방식

1. 분석 속도를 위해 이미지를 최대 256px로 축소하고 픽셀을 읽습니다. 투명한 픽셀은 제외합니다.
2. 각 픽셀을 sRGB에서 **CIELAB** 색공간으로 변환합니다. RGB 거리는 사람이 느끼는 색 차이와
   잘 맞지 않아서, 눈에 비슷해 보이는 색끼리 묶이도록 하기 위함입니다.
3. **k-means**(k-means++ 초기화)로 픽셀을 요청한 개수만큼의 군집으로 나눕니다.
4. 각 군집의 중심에 **가장 가까운 실제 픽셀 색**을 대표색으로 삼습니다.
   중심값을 그대로 쓰면 원본에 존재하지 않는 탁한 색이 나오기 때문입니다.
5. 군집이 차지하는 픽셀 수가 많은 순 — 즉 이미지에서 가장 넓게 보이는 색 순으로 정렬합니다.

작은 면적을 차지하는 강렬한 색(예: 포인트 컬러)은 개수를 늘리면 나타납니다.

## CMYK 값에 대하여

CMYK는 ICC 프로파일 없이 계산한 **근사값**입니다. 실제 인쇄에서 쓰이는 CMYK는 잉크·용지·
출력 장비에 따라 달라지므로, 이 값은 참고용으로만 쓰시고 정확한 인쇄 색 지정이 필요하다면
Pantone 등 별도 색상 체계나 출력소의 프로파일을 사용하세요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `styles.css` | 스타일 (라이트/다크 모드 자동 전환) |
| `app.js` | 색 변환, 샘플링, k-means 추출, PNG 내보내기 |

의존성 없는 순수 HTML/CSS/JavaScript입니다.
